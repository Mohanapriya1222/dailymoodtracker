# 🌙 Daily Mood Tracker
A simple mood tracking web app to log your daily emotions, write quick notes and track your mood history.
🔗live link: https://mohanapriya1222.github.io/dailymoodtracker/

## How to Run
1. Open index.html in browser
2. Or install it from the live link on your phone

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PWA - Manifest API
